# SentinelLite — Status Report

**Date:** 2026-09-02
**Run:** 2 — Hashing and Filesystem Engine

## Summary

This run implements PROJECT_SPEC.md section 27 (Run 2): the recursive
file-enumeration and SHA-256 hashing engine that the baseline and scan
systems (Runs 3-4) will build on. No storage, baseline, or GUI logic was
touched -- `gui/main_window.py`'s buttons remain intentionally disabled
placeholders until Run 5.

## Completed this run

- `core/models.py`: `FileRecord` (relative path, sha256, size,
  modified_time), `FileError` (path + message, for files that fail to
  read), and `ScanStatus` (NEW/MODIFIED/DELETED/UNCHANGED/ERROR, defined
  now so Runs 3-4 share one definition instead of duplicating it).
- `core/hasher.py`: `calculate_sha256()` -- incremental, chunked SHA-256
  hashing (default 1 MiB chunks, configurable via
  `config.DEFAULT_HASH_CHUNK_SIZE`), per section 7. Never loads a full
  file into memory. Raises `OSError`/`ValueError` rather than swallowing
  errors; callers decide how to handle failures.
- `core/filesystem.py`: `iter_file_paths()` and `collect_file_records()`
  -- recursive enumeration via `os.walk`, producing `FileRecord`s for
  every readable file and `FileError`s for files that fail to read
  (permission denied, removed mid-scan, etc.). A failure on one file or
  directory never aborts the scan (section 7.3 / 8.3); failures are
  logged and enumeration continues.
- Symlink policy decided and documented in `core/filesystem.py`'s module
  docstring (section 8.2): symlinked directories are not recursed into
  and symlinked files are skipped by default, to avoid cycles and to
  avoid silently monitoring content outside the selected directory.
  Callers may opt in via `follow_symlinks=True`; the GUI does not expose
  this in the MVP.
- `tests/test_hasher.py`: hashing tests (same file -> same hash, modified
  file -> different hash, empty file, large file with a small chunk size,
  missing file raises, invalid chunk size raises) and filesystem tests
  (recursive enumeration, relative POSIX-style paths, empty directory,
  an unreadable file becomes a `FileError` while the rest of the scan
  continues, an inaccessible subdirectory is skipped without aborting,
  a symlinked file is skipped by default).
