  1. `main()`'s success path — logging configured, `MainWindow()` built,

     `"Failed to create the main window."` and re-raised (the existing
     `except Exception: logger.exception(...); raise` in `app.py`).
  3. The `finally` block's shutdown log line still runs even when
     `mainloop()` itself raises.
  4. The `if __name__ == "__main__":` guard line — the one line the other
     three tests can't reach since they call `app.main()` directly —
     exercised via `runpy.run_path("app.py", run_name="__main__")` with
     `sys.exit` monkeypatched to capture the exit code instead of exiting
     the test process, and the same two seams patched on their source
     modules (`config.configure_logging`, `gui.main_window.MainWindow`)
     so the re-executed `from ... import ...` statements pick up the
     fakes.
  - Module-level `pytest.importorskip("tkinter")` guards the whole file,
    consistent with `tests/test_dialogs.py`: `app.py` imports
    `gui.main_window` unconditionally, which imports `customtkinter` (and
    therefore `tkinter`) at *module* level, so this needs a stricter guard
    than "no display" — it needs the `tkinter` package to be importable at
    all, which it isn't in this environment's tkinter-less headless venv.
