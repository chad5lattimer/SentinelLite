  any test in the suite.
- Added `tests/test_dialogs.py`: 11 direct unit tests for
  `gui/dialogs.py`, monkeypatching the underlying
  `tkinter.filedialog`/`tkinter.messagebox` functions (rather than the
  wrapper functions) so `choose_directory`, `choose_export_destination`,
  `confirm_replace_baseline`, `show_error`, and `show_info` run for real:
  correct keyword arguments (parent, initial dir/file, CSV vs. JSON
  filters and default extension), the cancel → `None` conversion, and an
  unknown `file_type` raising. Because only stdlib `tkinter` functions are
  replaced, these tests need no real Tk display or event loop — they skip
  cleanly (via `pytest.importorskip`) only where `tkinter` itself is
  unavailable, same convention as `tests/test_foundation.py`. No
  production code was changed — this is test-only, additive coverage.
